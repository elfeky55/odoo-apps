Dawami Connect

Mobile attendance for Odoo, with branch geofence and fake-GPS detection

Your employees check in from their own phones with the Dawami app. Dawami checks that they are really at the branch, then writes the attendance into Odoo with the result of that check. No fingerprint devices, and no Odoo license for every employee.

Free module · https://dawamihr.solutions Odoo 18 & 19 · Community & Enterprise · Odoo.sh

What your HR team gets in Odoo

📍 Branch geofence

Every check-in and check-out is marked Inside the branch or Outside the branch, with the distance in metres.

🛰️ Fake GPS detection

Check-ins from apps that fake the location are flagged in red, so "my friend checks in for me" stops.

📱 New device

Each employee is tied to one phone. A check-in from another phone is flagged for review.

🚗 Missions

Approved field missions are marked On a mission instead of outside the branch.

🔎 Needs review filter

One filter shows every suspicious record. The location is saved on Odoo's own latitude and longitude fields.

🔑 One-click connection

The module creates a dedicated integration user and API key. Nothing else to configure in Odoo.

Attendance from Dawami, inside Odoo

Colour badges in the standard Attendances list. Worked hours and overtime keep working as usual.

Good to know

  • This module is free. Dawami itself is a subscription service with a free trial: dawamihr.solutions.
  • Employees use the Dawami app (Android, iPhone through the browser, or web), so they do not need Odoo user accounts.
  • The connection uses one integration user, dawami.connect, with HR officer and Attendance administrator rights. On Odoo Enterprise it counts as one internal user.
  • Works without this module too (times only). With it, you also get the verification flags, distances and filters.
  • The API key is shown once. Generating a new key stops the old one; Disconnect archives the integration user.
  • Only administrators can create or remove the connection.
